# External-Validity Evidence v1

This directory is generated by:

```bash
python3 -m superturiya.external_validity bundle
```

The sealed input contract is `benchmark/external_v1/freeze_manifest.json`. `manifest.json` hashes the generated artifacts.

Credential-free evidence is complete. Real-provider LIVE evaluation remains blocked until `SUPERTURIYA_LLM_ENDPOINT`, `SUPERTURIYA_LLM_API_KEY`, and `SUPERTURIYA_LLM_MODEL` are configured. The local fake-provider tests validate protocol mechanics but are not reported as model-performance evidence.
