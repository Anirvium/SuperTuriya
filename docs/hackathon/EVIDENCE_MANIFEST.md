# Evidence Manifest

The committed `evidence/` bundle is generated by:

```bash
python3 -m superturiya.hackathon evaluate --mode frozen --output evidence
```

## Claim-to-artifact map

| Claim | Authoritative artifact |
|---|---|
| Fixed benchmark size, splits, class balance, and hidden labels | `evidence/final_evaluation.json` → `benchmark`; `benchmark/cases.json`; `benchmark/labels.json` |
| Baseline 3/12 and 25.00% CAVRR | `evidence/baseline_evaluation.json` → `metrics` and all 12 `results` |
| Final 11/12 and 91.67% CAVRR | `evidence/superturiya_evaluation.json` → `metrics` and all 12 `results` |
| +66.67 percentage points / +8 recoveries | `evidence/final_evaluation.json` → `improvement` |
| 0.00% safety regression rate | Final metrics plus each replay's `new_safety_failed_invariants` |
| Investigator and Adaptation are separate purposeful agents | `evidence/trajectories/investigator_*.json` and `adaptation_*.json` |
| Same-state replay and verification | `evidence/trajectories/replay_*.json`, including config/intervention/verification hashes |
| Difficult case safely rejected | `evidence/trajectories/replay_eval-012.json` |
| No hidden-label input to agents | Benchmark validation report and `agent_case_view` in `superturiya/adaptive.py` |
| Fail-closed governance | `tests/test_adaptive.py` and persisted audit records exercised by integration tests |

`evidence/EVIDENCE_MANIFEST.json` contains the machine-readable file list, case hash, label hash, evaluation mode, and frozen primary-metric contract. Runtime IDs, timestamps, and local latency are expected to change on regeneration; benchmark hashes, case outcomes, denominators, and metrics are expected to match.
