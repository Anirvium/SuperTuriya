# SuperTuriya Hackathon Constitution

1. Evidence before claims. Submitted claims must map to committed cases, trajectories, verifier results, or reproducible commands.
2. Deterministic truth first. Schemas, tool behavior, state transitions, invariants, replay verdicts, and aggregate metrics use deterministic code where practical.
3. No automatic learning promotion. Generated interventions, policies, and procedural memories begin as candidates. Only explicit review may approve them; activation is a separate transition.
4. Fair evaluation. Baseline and final system receive the same held-out cases. Gold labels are unavailable to evaluated agents and frozen before the final run.
5. Coverage cannot be hidden. The primary metric includes every eligible initially failing held-out case.
6. Typed bounded change. Unknown intervention operations are rejected. No production code deployment, credential change, unrestricted policy mutation, or consequential external action is permitted.
7. Honest reproducibility. LIVE runs actual model inference. FROZEN reuses stored outputs and reproduces verification and scoring, not inference.
8. Local-first judge path. Normal CPU, standard Python, SQLite, static HTML/CSS/JS, and deterministic fixtures are sufficient. No GPU or external datastore is mandatory.
9. Prior art is credited. SuperTuriya does not claim invention of trajectory normalization, failure localization, root-cause diagnosis, intervention, or replay.
10. Scope earns its place. A feature must improve user value, evaluation evidence, reproducibility, or safety; otherwise it remains off the default path.
